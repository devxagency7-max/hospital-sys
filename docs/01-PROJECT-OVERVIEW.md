# Hospital ERP — Project Overview

## Goal
Build a modern web-based Hospital ERP / Healthcare Management System from scratch.

The first phase is **Frontend only**.

## Frontend Stack
- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- RTL / Arabic-first UI
- Responsive design

## Backend
A `backend/` folder will exist in the repository structure, but **no backend implementation is required in the frontend phase**.

The frontend must use mock data and a clean API abstraction so the backend developer can connect real APIs later without rebuilding the UI.

## Repository
```text
hospital-erp/
├── frontend/
├── backend/
├── docs/
└── README.md
```

9. Laboratory
10. Radiology
11. Reports
12. Users / Roles / Permissions
13. Audit Log
14. Settings

## Core Principles
- Accuracy over visual effects.
- No fake business logic hidden in UI.
- Reusable components.
- Consistent design system.
- Permission-aware UI.
- Every important operation should have a clear status.
- Reports are a core feature, not an afterthought.
- The UI must be ready for API integration later.
