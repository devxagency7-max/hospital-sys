# Pre-Coding Checklist

Before implementing the first screen, confirm:

## Product
- [ ] Hospital name/branding
- [ ] Main user roles
- [ ] Main modules
- [ ] Required reports
- [ ] Required exports
- [ ] Arabic terminology
- [ ] Existing system pain points

## UI
- [ ] Desktop target
- [ ] Responsive behavior
- [ ] RTL
- [ ] Color system
- [ ] Typography
- [ ] Icons
- [ ] Tables
- [ ] Forms
- [ ] Modal behavior
- [ ] Notifications

## Architecture
- [ ] Frontend folder structure
- [ ] Component strategy
- [ ] Mock data strategy
- [ ] API abstraction
- [ ] State strategy
- [ ] Routing strategy

## Integration Preparation
- [ ] API naming conventions agreed
- [ ] Data contract format agreed
- [ ] Pagination contract agreed
- [ ] Error response shape agreed
- [ ] Authentication placeholder defined
- [ ] Permission model documented

## Quality
- [ ] No backend implementation
- [ ] No database dependency
- [ ] No AI
- [ ] No hard-coded production credentials
- [ ] No sensitive patient data in mock data
