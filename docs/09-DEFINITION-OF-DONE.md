# Definition of Done

A frontend feature is considered complete only when:

- The page is responsive.
- RTL works correctly.
- Loading state exists.
- Empty state exists.
- Error state exists.
- Success feedback exists where applicable.
- Form validation exists.
- Destructive actions require confirmation.
- Tables support required search/filter/sort/pagination behavior.
- Mock data is isolated from UI.
- No console errors.
- No broken links/buttons.
- Components are reusable where appropriate.
- UI follows the design system.
- The feature works with realistic data volumes.
- The code is committed on a feature branch.
- The feature is reviewed before merging into `main`.
