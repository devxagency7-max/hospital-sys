# Reporting Specification

Reporting is a core module.

## Required Export Formats
- PDF
- Excel
- CSV
- Print

## Report Flow

```text
Select Report
      ↓
Filters
      ↓
Preview
      ↓
Validate Result
      ↓
Export
```

## Critical Requirement
The system must never silently export an incomplete report.

If a user selects:
- Services
- Payments
- Outstanding balance

the generated report must contain all selected sections.

If any required section fails:
- Show an error.
- Explain the failed section.
- Do not export the incomplete report.

## Patient Statement Example

Header:
- Hospital name
- Patient name
- Patient ID
- Date range
- Generated by
- Generated date

Sections:
- Services
- Invoices
- Payments
- Discounts
- Refunds
- Outstanding balance

Summary:
- Total services
- Total invoiced
- Total paid
- Total refunded
- Remaining balance

## Financial Reports
Required UI for:
- General ledger
- Trial balance
- Revenue
- Expenses
- Receivables
- Payables
- Cash flow
- Income statement

## Inventory Reports
Required UI for:
- Stock balance
- Stock movement
- Low stock
- Expired items
- Near expiry
- Warehouse valuation

## Report Filters
Reusable filters:
- Date from/to
- Department
- Clinic
- Doctor
- Warehouse
- Supplier
- Patient
- Payment method
- Status
- Category

## Report Preview
Preview should look close to the final PDF/print output.

## Export UI
Provide clear actions:
- Preview
- Print
- Export PDF
- Export Excel
- Export CSV
